## What lives here

- `opengate-production-website` — opengatekz.com, Next.js, two locales.
- `opengate-os` — the operations backbone: MCP server, CLI, the Postgres store, the crons, and the dashboard.

## Working here

Every repository carries a `CONTRIBUTING.md`. The short version: read access, fork, branch, pull request. A pull request is the card. A founder merges after looking at the rendered result, never at the diff alone.
